一个组件，统一管理操作状态

通过全局 Button 类增强原生按钮，传入文字、用途样式与点击回调。回调支持 Promise，组件在操作完成前锁定点击。 

// HTML
<button id="submit"></button>

// JavaScript
const submit = new Button(document.querySelector('#submit'), {
  label: '保存更改',
  variant: 'primary',
  loadingLabel: '保存中…',
  successLabel: '保存成功',
  successOnComplete: true,
  onClick: async () => {
    await saveChanges();
  }
});

submit.update({ label: '发布项目', disabled: false });
// 移除事件、清理成功计时器
submit.destroy();

配置参数

参数 默认值 说明
label 按钮 按钮文字，按纯文本渲染
variant primary primary / secondary / danger
onClick 空回调 同步或异步操作，接收点击事件
disabled false 禁用时阻止点击与键盘触发
loadingOnClick true 执行回调时显示加载状态
loadingLabel 处理中… 加载状态的可访问文字
successOnComplete false 回调成功后显示成功状态
successLabel 操作成功 成功状态文字
successDuration 1800 成功反馈持续时间，单位毫秒
icon 空 文字图标，作为装饰元素显示

反馈与可访问性

操作中使用原生 disabled 锁定按钮，并通过 aria-busy 标记加载状态。组件派发 buttonstatechange、buttoncomplete 与 buttonerror 事件，可用于页面状态提示。回调失败时恢复按钮，复制操作仅在剪贴板写入成功后显示“已复制”。

所有示例均在本地运行。保存与删除使用模拟任务，复制操作会写入系统剪贴板。
