# UI 走查清单（分层，外框 + 演示）

用法：每次视觉改动后，按下面的层**逐层**过一遍。每层先跑能自动量的部分（`tests/ui_audit_headless.cjs`、`tests/geometry_headless.cjs`、`tests/hint_position_headless.cjs`），再按「人工目检」逐个元素放大看截图。只看整体印象不算走查完成。

记录方式：发现的问题写进 `/workspace/bench/ui-audit/findings.md`，写清楚层、页面、元素、宽度、状态、截图和修复提交，并统计每层发现/修复数。

## 0. 覆盖范围（每层都要过完以下元素）

- 外框：顶栏（品牌、导航、下拉面板、搜索按钮 ⌘K、移动端目录按钮）、搜索弹窗（输入框、结果、键盘提示）、面包屑、标签芯片、按钮（主/次/文字/图标）、卡片（画廊卡、动效卡、简单卡）、使用卡 / 提示词卡（复制、✓ 已复制）、底部栏（移动端）、页脚。
- 页面类型：首页、5 个栏目页、条目页（组件 / 交互 / 设计基础 / 场景 / AI 技能）、设计系统页、测评页、404。
- 演示：192 条的交互演示和画廊缩略图（Shadow DOM 内）。
- 宽度：1440 / 1024 / 768 / 390（390 用触屏模式）。

## 1. 对齐

| 检查项 | 标准 | 自动 / 人工 |
|---|---|---|
| 图标与文字垂直居中 | 图标**墨迹**中心与相邻文字墨迹中心（中文）或文字框中心（纯拉丁）相差 ≤1px。量真实像素，不量盒子 | 自动：ui_audit icon |
| 文字基线 | 同一行混排的中文、数字、英文基线一致，编号（01）与名称同一基线 | 人工 |
| 左边缘 | 同一列的标题、正文、按钮、卡片左边缘对齐；容器内边距一致 | 人工 + geometry spacing |
| 一行内等高 | 同一行同类元素（按钮、芯片、标签页、卡片）高度一致 | 自动：ui_audit rows |
| 文本字符图标 | 禁止用 ⌄ ▼ 这类文字字形当下拉箭头（字形贴基线，不居中），统一用 SVG 图标 | 人工 + 自动 |

## 2. 图标

| 检查项 | 标准 |
|---|---|
| 尺寸 | 12px（导航、芯片内）/ 16px（按钮内）/ 20px（独立图标按钮），同一组件内统一 |
| 描边 | 1.5px，圆头圆角，颜色用 currentColor，随文字状态变色 |
| 与文字间距 | 4–6px（导航 4px，按钮 6–8px），同类组件一致 |
| 方向 / 状态 | 下拉展开时箭头旋转 180°；外链用 ↗；返回用 ←；方向与动作一致 |
| 无障碍 | 装饰图标 aria-hidden="true"、focusable="false"；纯图标按钮要有可读名称 |

## 3. 字体排版

- 字号只用规范值。外框：12 / 13 / 14 / 16 / 18 / 22 / 28 / 36（首页标题 ≤760px 时用 26）。演示：12 / 13 / 14 / 16 / 20 / 28，加上容器宽度覆盖值 15 / 22 / 24。
- 行高只用规范倍数。外框：1.3 / 1.5 / 1.7。演示：1.2 / 1.35 / 1.4 / 1.5 / 1.6。单行控件可以用等于高度的行高。
- 字重只用 400 / 500 / 600 / 650。
- 颜色只用色板（tokens.css / demo-spec.css）中的值。
- 最小字号 12px。
- 自动：ui_audit type；batch4 检查小于 12px 的文字。

## 4. 颜色与对比度

- 正文对比度 ≥4.5:1，大字和图标 ≥3:1；悬停、选中、禁用态也要达标（batch6 contrastLabels）。
- 外框强调色只用蓝 --blue，演示只用紫 --ds-accent，两套颜色不混用。
- 状态色（成功/警告/危险）只表达语义，不用来装饰。

## 5. 间距与圆角

- 间距只用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 相邻独立按钮间距 ≥8px；0 间距只允许出现在真分段按钮里（单外框 + 1px 分隔线 + 两端圆角）。
- 嵌套圆角：内圆角 ≤ 外圆角 − 间距，最小 6px。舞台 16 > 面板 12 > 控件 8 > 芯片 6。
- 自动：geometry_headless 的 radius、spacing、segmented 项。

### 5.1 画廊缩略图与瀑布流

- 缩略图舞台内边距只用一个 token（`--ds-thumb-inset:var(--thumb-inset,16px)`），内容卡到舞台四边距离相等（≤1px）。
- 内容卡铺满舞台宽度，舞台高度跟随内容；严格同心圆角：内容卡 14 + 四边内缩 17 = 舞台 31，舞台 31 + 画廊边框 1 = 画廊卡 32；变量及四宽度表见 `docs/design-system.md`。
- 分类画廊用瀑布流（CSS columns，无 JS）：1440/1024 三列/两列，768 两列，390 两列；列间距 = 行间距（16px，≤760 为 12px）。
- 阅读顺序按列自上而下（DOM 顺序 = Tab 顺序 = 视觉顺序）。
- 不再要求同一行卡片等高、标题对齐。
- 自动：ui_audit_headless 的 `inset`、`concentric`、`gap`；`brand` 按宽度比较所有受审页面的标志左边界（相对众数偏差 ≤1px）。
- `tests/r1_headless.cjs` 输出四类页面、四个宽度和悬停/触屏/减弱动态模式的 `.brand` x、单个按钮缩略图各层圆角、内缩及控件 computed display，并检查导航不换行。

## 6. 组件状态（每个可交互元素都要看全）

默认、悬停、按下、聚焦（键盘 Tab）、禁用、展开/打开、选中。

- 悬停：颜色或底色变化，不位移、不改尺寸。
- 聚焦：2px 焦点环清晰可见，四边都不被裁切（外框蓝，演示紫或深色）。常见裁切原因：父级 overflow:hidden、后一个兄弟元素的白底盖住右边。自动检查：focus_ring_headless。
- 展开：aria-expanded 同步，箭头旋转，面板与触发器对齐。
- 选中：aria-selected / aria-pressed 同步，选中指示器覆盖实际选中项。
- 禁用：降低不透明度，鼠标为 not-allowed，不响应点击。
- 自动：ui_audit 的状态截图（导航 / 复制 / 搜索按钮 × 默认 / 悬停 / 打开 / 聚焦）。截图需要人工逐张看。

## 7. 响应式（1440 / 1024 / 768 / 390）

- 无横向溢出（allpages）。
- 文字截断要有省略号且有完整提示；不允许字被裁掉半个。
- 换行后行内图标仍然居中，按钮不变形。
- 390 四边留白 ≥16px，触控目标 ≥44px。
- 导航在 ≤1180 隐藏编号、在 ≤1023 换成目录按钮，过渡点前后都要截图看。

## 8. 动效与减弱动态

- 时长 150–320ms，只做位移和透明度变化。
- 减弱动态（prefers-reduced-motion）下直接显示终点，无旋转、无缩放、无循环动画。
- 箭头旋转、面板展开、卡片悬停在减弱动态下没有过渡。

## 9. 人工目检流程（截图逐个元素看）

1. 每种页面类型 × 4 个宽度，截外框：顶栏、下拉打开、搜索打开、面包屑、芯片、卡片、提示词卡（默认 / 已复制）、页脚。
2. 截图放大到 3 倍后逐个元素看，顺序为：对齐 → 图标 → 字 → 色 → 间距圆角 → 状态。
3. 每个问题都要写进 findings：页面、元素、宽度、状态、截图、修复提交，修完后复拍对比。

## 10. 自动化工具与用法

先构建：`python3 -B scripts/build_site.py`，跑测试期间不改文件。

| 工具 | 检查什么 | 阈值 |
|---|---|---|
| `node tests/ui_audit_headless.cjs [路由过滤] [--widths=1440,1024,768,390] [--inject=CSS]` | icon：图标/字形中心 vs 文字墨迹中心；type：字号、行高、字重、颜色是否在 token 内；rows：同一行控件/卡片等高；filled：实心按钮不带灰描边；inset：画廊缩略图里单张内容卡到灰色舞台四边距离相等；gap：瀑布流画廊列间距 = 行间距；brand：逐宽度比较受审页面标志左边界众数；navx：逐宽度采集每页可见桌面导航项及搜索按钮的左边界列表，与受审页面中出现次数最多的列表比较；状态截图 | 偏差 ≤1px；navx 任一位置偏差 >1px 或项目数量不同即报错，纳入汇总与退出码；token 外 0 处；结果写 `output/ui-audit/report.json`，有问题退出码 1 |
| `node tests/focus_ring_headless.cjs <站点地址> [--widths=1440,1024,768,390]` | 8 类页面 × 指定宽度，Tab 遍历外框所有可聚焦元素，按像素检查焦点环四边是否都画出来 | 0 处缺边 |
| `geometry_headless` / `hint_position_headless` / `design_system_headless` | 演示几何、提示标签位置、设计系统页 | 全部通过 |
| 单元测试 `python3 -B -m unittest discover -s tests -p 'test_*.py'` | 构建产物契约 | 全部 OK |

自测：`--inject='.nav-caret{top:3px}'` 必须报出 icon 偏差，证明检查本身有效。

例外（不按 token 查）：6 种视觉风格和排版标本、`.ds-type-sample`、`[data-ui-audit-specimen]`、里程表数字、纯图标文本、svg/pre/code/kbd/提示词正文。
