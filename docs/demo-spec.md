# 演示统一规格（Demo Spec）v1

> 适用范围：「Vibe Design 速查」全部条目里的演示（UI 元素、动效、指南、设计基础、AI 实现）。
> 网站外框（导航、使用卡、搜索）仍按 PRD §15/§16，不受本规格影响。
> 参考了这些做法：Linear 与 Vercel Geist 的克制中性色和细边框，Radix 的状态完整性，Apple HIG 的动效节奏和减弱动态，Rauno Freiberg 一类动效研究站「一个舞台只讲一件事」的展示方式。

## 0. 五条原则

1. **一个舞台只讲一件事。** 演示里只放说明这个条目所必需的东西，其余全部去掉。
2. **用真实内容。** 用真实的图片、像样的文案和数字。不用「Lorem」，也不用简笔画、色块小人。
3. **克制。** 中性灰打底，只用一种强调色（紫）。颜色只用来表示「这是重点」或「这是状态」。
4. **全站一致。** 所有演示用同一块舞台、同一套字号、圆角、阴影和动效节奏，看起来出自同一个人之手。
5. **能上手。** 能交互的演示把各个状态都做全，在手机上也能点。

## 1. 舞台（演示画布）

| 位置 | 屏幕宽度 | 比例 | 最小高度 | 内边距 |
|---|---|---|---|---|
| 条目页主演示 | ≥ 1024 | 16:10 | 320px | 32px |
| 条目页主演示 | 768–1023 | 3:2 | 300px | 24px |
| 条目页主演示 | < 768 | 4:3 | 260px | 16px |
| 栏目页格子 / 搜索缩略 | 全部 | 4:3 | — | 16px（整体缩放显示） |

- 内容放不下时，舞台可以按内容增高，但不能截断，也不能出现横向滚动。
- 舞台底色 `--ds-stage: #F7F7F8`。上面铺一层很淡的点阵（24px 间距，点色 `rgb(17 24 39 / .05)`），用来营造「工作台」的感觉。点阵只是装饰，不承担识别，减弱动态下照常显示。
- 舞台外框：圆角 12px，1px 边 `#E4E7EC`，不加阴影。
- 舞台里的主体放在一张「承托面」上：白底，圆角 16px，阴影用 `--ds-shadow-1`。主体本身就是卡片的（如卡片、弹窗）不再多套一层。
- 主体在舞台里上下左右居中。多个元素按 8 的倍数排开，组与组之间留 24px。

## 3. 字号

字体沿用外框的系统中文字体栈，数字用 `font-variant-numeric: tabular-nums`。

| 令牌 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| `--ds-text-caption` | 12 / 1.5 / 400 | 提示、注释（下限，不能更小） |
| `--ds-text-label` | 13 / 1.4 / 500 | 标签、按钮小号、表头 |
| `--ds-text-body` | 14 / 1.6 / 400 | 正文、输入内容、按钮默认 |
| `--ds-text-strong` | 16 / 1.5 / 600 | 卡片标题、列表主文字 |
| `--ds-text-title` | 20 / 1.35 / 600 | 弹窗标题、区块标题 |
| `--ds-text-display` | 28 / 1.2 / 650 | 大数字、首屏标题（字距 -0.01em） |

每个演示最多用 3 级字号。

## 4. 圆角、阴影、间距

- **圆角**：6（标签、小按钮）· 8（按钮、输入框）· 12（卡片、图片）· 16（承托面、弹窗、抽屉）· 999（胶囊、头像）。嵌套时内层圆角 = 外层圆角 − 间距，最小 4。
- **阴影**（用两层：一层近处、一层远处，颜色用墨色而不是纯黑）
  - `--ds-shadow-1` 静止：`0 1px 2px rgb(17 24 39 / .06), 0 1px 1px rgb(17 24 39 / .04)`
  - `--ds-shadow-2` 悬停或浮起：`0 10px 24px -8px rgb(17 24 39 / .16), 0 2px 6px rgb(17 24 39 / .06)`
  - `--ds-shadow-3` 浮层（弹窗、下拉、提示框）：`0 24px 64px -16px rgb(17 24 39 / .28), 0 4px 12px rgb(17 24 39 / .08)`
  - 浮层另加 1px 边 `rgb(17 24 39 / .08)`，在浅底上也能看清边界。
- **间距**：按 4 的倍数，4 / 8 / 12 / 16 / 24 / 32 / 48。
- **控件高度**：小 32 · 默认 40 · 大 48。手机上能点的东西至少 44×44。

## 5. 动效

| 令牌 | 时长 | 用在 |
|---|---|---|
| `--ds-dur-instant` | 100ms | 按下、勾选 |
| `--ds-dur-fast` | 160ms | 悬停、颜色变化、焦点 |
| `--ds-dur-base` | 240ms | 小元素出现、提示框、下拉 |
| `--ds-dur-slow` | 360ms | 弹窗、抽屉、卡片展开 |
| `--ds-dur-scene` | 560ms | 整块交叉淡化、页面切换、揭示（上限） |

| 令牌 | 曲线 | 用在 |
|---|---|---|
| `--ds-ease-standard` | `cubic-bezier(.2, 0, 0, 1)` | 状态变化 |
| `--ds-ease-out` | `cubic-bezier(.16, 1, .3, 1)` | 进入（快出慢停） |
| `--ds-ease-in` | `cubic-bezier(.4, 0, 1, 1)` | 离开 |
| `--ds-ease-spring` | `cubic-bezier(.34, 1.36, .64, 1)` | 小幅弹性（开关、点赞），只用在小元素上 |

- 离开的时长约为进入的 0.75 倍。
- 只给 transform、opacity、filter 做动画，不给宽高和位置做动画。
- 条目本身讲的就是某种时长或曲线时，照条目原来的数值，不强套本表。
- 自动循环的演示每轮之间停 1.2 秒，并保留「重播」。

## 6. 图片

- 全部来自 `site-src/demo-assets/`（清单见 `manifest.json`），每张图有 640 和 1280 两种宽度，用 `srcset` 按需加载。
- `object-fit: cover`，圆角跟着容器走，内侧加一圈 1px `rgb(17 24 39 / .06)` 描边，避免浅色图和底色糊在一起。
- 图片加载前先显示该图的主色（清单里有 `dominant` 字段），不显示白块。
- 图上压文字时，底部加从透明到 `rgb(0 0 0 / .55)` 的渐变遮罩，白字对比度 ≥ 4.5:1。
- 不用真人脸，不用带品牌标志的图。缺合适的图时，用本规格的渐变（紫到浅紫、青到浅灰）代替，不画简笔画。

## 7. 状态

所有能交互的演示，下面这些状态能做的都要做：

| 状态 | 表现 |
|---|---|
| 默认 | — |
| 悬停 | 底色加深一级，或阴影从 1 到 2；只用 `--ds-dur-fast` |
| 按下 | 底色再深一级，并缩放到 0.98（只按下的那一下），不能和默认长得一样 |
| 键盘聚焦 | 2px `--ds-accent` 焦点环，外偏移 2px；只在键盘操作时显示 |
| 禁用 | 透明度 0.45，鼠标显示禁止，不响应悬停 |
| 加载 | 文字前加 14px 转圈，宽度不跳 |
| 出错 | 边框和说明文字用 `--ds-danger`，说明里写清怎么改 |
| 成功 | 用 `--ds-success`，1.6 秒后回到默认 |

外框的「状态切换」按钮要能把每一个状态固定显示出来（已有机制，沿用）。

## 8. 减弱动态（系统开启「减少动态效果」时）

- 位移、缩放、旋转一律去掉，换成 ≤ 150ms 的淡入淡出，或者直接显示最终状态。
- 自动循环停止，停在最能说明问题的那一帧。
- 保留已有的「播放一次」按钮：用户主动点了才完整播放一次。
- 点阵、阴影这类静态装饰照常显示。

## 9. 提示与说明文字

- 字号 ≥ 12px，对比度 ≥ 4.5:1。舞台上用 `--ds-ink-2`，不用浅灰。
- 每个演示最多一条操作提示，放在舞台左下角：白底胶囊、1px `--ds-line` 边、12px 字、前面配一个图标。
- 提示用中文动词开头，写清做什么：「把鼠标移到卡片上」「点一下按钮」。手机上自动换成「点一下…」。
- 演示里的示例文案用中文，短而真实（如「保存修改」「已发送给 3 位同事」），不用「按钮 1」「Item A」。

## 10. 手机（< 768）

- 舞台换成 4:3，内边距 16。内容放不下就按比例缩小或换成竖排，不能截断。
- 靠悬停才能看到的效果，改成点一下切换，再点一下复原。
- 可点区域 ≥ 44×44，相邻两个之间至少隔 8px。
- 不出现横向滚动；弹窗、抽屉限制在舞台内部。
- 文字不小于 12px，缩放演示时也算缩放后的字号。

## 11. 落地方式（给开发看）

- 所有令牌写在 `site-src/redesign/demo-spec.css`，以 `--ds-*` 变量注入每一个演示的 Shadow DOM（排在源样式后面、无障碍补丁前面）。
- 公共外壳类：`.ds-stage`（舞台与点阵）、`.ds-surface`（承托面）、`.ds-hint`（操作提示胶囊）、`.ds-caption`（注释）、`.ds-img`（图片处理）。
- 每个演示的美化写在 `site-src/redesign/demo-skins/<条目 slug>.css`，只改外观；需要换内容（图片、文案）时，在 `demo-skins/<slug>.html` 里覆盖演示内部结构，交互脚本依赖的 id、class、data 属性一律保留。
- 条目的行为、验收要求、提示词文字都不变。

## 嵌套圆角与间距（2026-11-13 补充，强制）
- **外圆角 = 内圆角 + 间距。内圆角永远不大于外圆角。** 间距很小时内圆角取 `max(外圆角 − 间距, 6px)`。
- 统一层级（`demo-spec.css` 变量）：舞台 `--ds-r-stage` 16 ≥ 主体卡片 `--ds-r-surface` 16（离舞台边 ≥ 24/16）> 卡内面板 `--ds-r-panel` 12 > 控件 `--ds-r-control` 8 > 标签 `--ds-r-chip` 6；最小 `--ds-r-min` 6。画廊缩略格内的舞台 = 卡片 12 − 边框 1 = 11。
- 胶囊和圆形（半径 = 短边一半）按形状处理，不参与比较，但离外框角的距离要 ≥ 外框圆角（提示胶囊离舞台边 16）。
- 按钮不贴任何其它框：与相邻框（卡片、预览区、图片、输入框）至少 8px，与预览区至少 12px；同一控件组（分段、分页、拆分按钮）内部除外。
- 卡片不窄于约 320px：「它怎么动」卡片按 `minmax(min(100%,320px),1fr)` 排，390 下单列；播放按钮放在卡片标题行右侧，离卡片四边 16px。
- 选中指示器（滑块、下划线）按真实目标元素测量位置和宽度，尺寸变化时重新计算，偏差 ≤ 2px。
- 自动检查：`tests/geometry_headless.cjs`（1440/768/390 全部条目页：嵌套圆角、按钮间距、文字裁切/溢出、指示器偏移、元素比内容窄）。
