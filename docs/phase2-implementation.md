## 实施顺序与检查

1. 在 `entries.py` 加入独立 JSON 编辑层和宽松校验，冻结一期构建 SHA-256 清单，核对空编辑层的构建逐字一致。

4. 填写指定 10 条样本，固定按钮、网格和交叉淡化的测评验收，验证三条口语查询。
5. 按组件分组填写全部 75 条，校验别名唯一性、验收句、字段和审核标记。

每步运行 `python3 scripts/build_site.py` 和 `python3 -m unittest discover -s tests -p 'test_*.py'`，随后保存顺序补丁、累计快照及日志。
