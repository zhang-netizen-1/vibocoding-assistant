# 界面速查网站第一版实施计划

**目标：**将现有 UI 元素速查与动效速查整合为可本地预览、可静态部署的三页网站，保留原有演示与复制功能。

**架构：**现有两份 HTML 继续作为栏目内容源。`scripts/build_site.py` 明确读取这两份文件和 `site-src/` 资源，生成 `dist/index.html`、`dist/ui/index.html`、`dist/motion/index.html`；构建时注入共用站点导航、元信息和条目分享功能。`dist/` 不读取工作区其他内容。

**技术：**Python 3 标准库、HTML、CSS、JavaScript；无需运行时后端和外部前端依赖。

## 工作项

- [x] 创建首页与共用导航样式，明确两类内容入口和使用方法。
- [x] 创建站点构建脚本：先生成动效内容，再将两份速查页包装成栏目页；输出目录采用白名单，拒绝覆盖非构建目录。
- [x] 为 94 个现有条目保留原 ID，提供直达链接与复制链接按钮。
- [x] 补齐页面描述、图标、键盘跳转与响应式导航。
- [x] 添加构建完整性测试，验证页面、卡片数、链接及输出白名单。
- [x] 在真实浏览器检查首页、两个栏目、搜索、复制、条目链接与移动端布局。
- [x] 写明本地预览及静态部署方式，保持所有无关文件原状。

## 验收标准

1. 从首页两次点击以内到达任一速查条目；栏目间可相互切换。
2. UI 47 个组件和动效 47 个效果均可浏览，原有交互及需求复制有效。
3. 条目 URL 包含稳定锚点；复制出的链接可在新页面直接定位。
4. 构建产物只包含三页与共用资源，不包含面试工具、象棋游戏、研究稿或历史备份。
5. 1440、390 与 344 像素宽度均无页面级横向溢出；键盘焦点可见、减弱动态可用。
